# Original synthetic proposals

These four files preserve the original Decide and Test Review synthetic controls
and proposed calibration manifests byte-for-byte. `inventory.json` records their
hashes. The live proposed controls remain in `suites/transfer/`.

These are historical snapshots, not runnable calibration packages: their relative
`specFile` paths describe their original location. They contain no private model
transcripts or operator-acceptance records. Do not restore them over current
proposals or treat their criterion expectations as established truth.

Decide's original negative had an underspecified revisit trigger. Its prospective
replacement made that trigger concrete but still disagreed on C3 because the same
answer misstates permitted spending authority. Decide remains held.

Test Review's original negative expected C3 PASS despite an invented missing-zero
claim. C3 requires source grounding as well as honest execution disclosures. Its
prospective correction changes only that expected vote to FAIL; the answer and
rubric are unchanged. Shared exact-judgment reuse validated the correction without
another judge call. See the current observation report for scope and limitations.
